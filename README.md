# The Curious Casebook

A short Python detective game set in a fictional digital archive.

## Case 01 · The Missing Photograph

A photograph has vanished from an exhibit. The curator has its original caption and three catalog records. Compare the clues and figure out which box holds the missing photograph.

## How to play

Open this repository in GitHub Codespaces, or open the project folder in a terminal with Python 3. No extra packages are needed.

Run this command from the project folder:

```bash
python3 game.py
```

Read the caption and catalog records, then enter a box number. If your guess is wrong, the game gives you a hint and lets you try again. Enter `Q` to quit at any prompt.
